# Web3 Mobile Wallet Demo

This is a React Native + Expo demo for Web3 mobile wallets.

Features:
- Connect wallet (WalletConnect)
- Show ETH balance
- Show USDT balance (Sepolia testnet)
- Copy address
- Disconnect wallet

Tech stack:
- React Native + Expo
- TypeScript
- ethers.js
- WalletConnect

This demo is designed to show Web3 startups how I can quickly implement a mobile wallet interface.
